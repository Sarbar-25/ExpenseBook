# ExpenseBook 💰

ExpenseBook is a personal finance management web application designed to help users track expenses, manage lending and borrowing activities, set reminders, and gain insights into their monthly financial habits.

This project was developed as a student project to solve real-world personal expense management problems while learning modern web development technologies.

---

## ✨ Features

### 📊 Expense Management
- Add and manage daily expenses.
- Categorize transactions.
- Track spending history.
- Monthly expense analysis.

### 💸 Lend & Borrow Management
- Record money sent to others.
- Record money received from others.
- Track pending balances.
- Separate sender and receiver records.

### 📅 Reminder System
- Create payment reminders.
- Upcoming and due reminder tracking.
- Calendar-based reminder visualization.

### 📈 Dashboard Analytics
- Monthly summaries.
- Total income and expenses.
- Monthly balance tracking.
- Financial overview cards.
- Interactive charts and visualizations.

### 🤖 AI Features
- AI-powered chatbot assistance.
- Financial guidance support using Groq API.

### 📱 Sharing Features
- WhatsApp sharing support.
- PDF export functionality.

### ☁️ Cloud Integration
- Firebase Authentication.
- Firebase Firestore Database.
- Firebase Hosting deployment.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Sarbar-25/ExpenseBook.git
```

Navigate to the project folder:

```bash
cd ExpenseBook
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Deploy to Firebase:

```bash
firebase deploy --only hosting
```
